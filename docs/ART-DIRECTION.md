# Mancar Software — expressive studio direction

The presentation feels inventive and technically precise through oversized editorial typography, saturated color fields, and geometric forms assembling into useful structures. Motion expresses the journey from an idea to a working digital product. The strongest visual moments introduce the studio, its capabilities, its method, and the invitation to collaborate.

- **Audience and action:** business owners, collaborators, and developers should understand the offer, inspect the four projects, and start a conversation.
- **Personality:** confident, inventive, practical. Avoid toy-like effects, flashing, fake product interfaces, and arbitrary ornament.
- **Concept:** from idea to working product. Windows, connected modules, and assembled grids stand for the products Mancar develops.
- **Typography:** Segoe UI Bold for large, stationary statements; regular Segoe UI for supporting copy. Native Markdown carries project facts and links.
- **Color:** graphite `#101416` anchors the page; cobalt `#284BE8` carries the studio statement; cyan `#54DCEC` signals web experiences; lime `#B4E878` signals structured systems; coral `#FF866E` carries the invitation. Ivory `#F4F2EB` provides readable type. Colors appear in defined sections, not a badge wall.
- **Composition:** alternate a cobalt studio cover, dark project showcases, an illustrated capability panel, a process sequence, and a coral closing panel. Avoid repeating the same panel layout throughout.
- **Imagery:** real repository interfaces take center stage in project showcases, with short screen sequences and deliberate detail crops. Clinical screens use fictional demonstration data; website screens use repository content. Geometric artwork supports the studio story. Project logos remain unchanged and transparent, without separate backing rectangles.
- **Geometry and spacing:** 32–48 px gutters; clear rectangular structures, circular connections, a small consistent corner radius. No glow or glass effects.
- **Links and controls:** normal GitHub links and disclosure elements. Color and motion never substitute for a functional link.
- **Motion:** purposeful assembly, orbit, and traversal in slow seamless cycles. Main text remains stationary. The new motion lives across the presentation rather than on the logos.
- **Responsive:** dedicated 560 px mobile compositions reflow display text and reposition illustrations. Reduced-motion picture sources use complete static frames; the presentation remains understandable without playback.

GitHub compatibility requires local GIF/PNG/SVG assets and supported Markdown/HTML. Preview-only CSS must never become a requirement of the README.

## Project evidence expansion

The presentation will feel confident and tangible through large product screens, stationary editorial captions, and distinct cyan, teal, blue, and warm terracotta project accents. Motion will walk through actual interface states at a readable pace. A conceptual workflow-to-screen sequence will explain the studio's method without pretending to be archived design history. A factual editorial introduction will present Mancar through its work, without invented staff biographies, locations, or portraits. The closing question will connect directly to the visitor's everyday manual work.
