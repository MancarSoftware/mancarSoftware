# काम को करीब से देखें

परियोजना इंटरफ़ेस के स्थिर स्क्रीनशॉट। सभी चिकित्सकीय नाम और रिकॉर्ड काल्पनिक डेमो डेटा हैं; वेबसाइट सामग्री रिपॉज़िटरी से है। ये पूर्वावलोकन इंटरफ़ेस डिज़ाइन दिखाते हैं, प्रोडक्शन परिनियोजन या संपूर्ण बैकएंड परीक्षण का प्रमाण नहीं हैं।
